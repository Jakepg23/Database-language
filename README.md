# Daycare Management System

Full-stack web application built with Spring Boot (Java) and Oracle Database.

## Features
- Child enrollment system
- Service management
- Database integration with Oracle
- SQL scripts for database structure and operations

## Technologies
- Java (Spring Boot)
- Oracle Database
- HTML, CSS, JavaScript
- Maven

## Setup
1. Clone the repository
2. Configure Oracle DB connection
3. Run the application using Spring Boot
